# Domain glossary

| Term                       | Meaning                                                                 |
| -------------------------- | ----------------------------------------------------------------------- |
| Institution / tenant       | School customer and primary isolation boundary.                         |
| Campus                     | Physical location within an institution; deferred.                      |
| Academic year / session    | Historical administrative period; closing must not erase prior records. |
| Grade / class              | Level such as Class 6; independent of year and section.                 |
| Section                    | Year-specific group such as Class 6–A.                                  |
| Student                    | Persistent identity across years and promotions.                        |
| Enrollment                 | Participation in a year/class/section with status and effective dates.  |
| Guardian                   | Caregiver with relationship-specific authority and contact preferences. |
| Staff / teacher            | Employment identity; can exist without a login.                         |
| Teaching assignment        | Teacher responsibility scoped to year, section and subject.             |
| Attendance session         | Dated roster workflow; proposed draft, submit and correction lifecycle. |
| Grade policy               | Versioned assessment calculation rules.                                 |
| Charge / payment / receipt | Distinct financial obligations, settlement and issued evidence.         |
| User / membership          | Login identity versus independently verified institution association.   |
