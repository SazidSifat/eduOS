# Workspace instructions

Read the root instructions and `docs/architecture/frontend.md`. Follow the sastho-marketer folder structure: thin src/app/**/page.tsx routes, colocated _component/ presentation/hooks and _api/ clients/queries, shared components/layout and components/providers, infrastructure in lib/, router.tsx at the source root and theme preference in stores/. Use central typed API calls and Query keys scoped to identity/institution. Clear cached server state after logout. The root page redirects to /login; authenticated login visits redirect to /workspace. There is no landing page. \_\_root.tsx connects components/layout/root-layout.tsx; individual pages own their main landmark and shell. Keep routeTree.gen.ts generated; tsr.config.json excludes helper directories and non-route files. Use route.tsx for nested TanStack route layouts. The Vite plugin handles code splitting; keep accessible loading/error/empty states. UI-only checks never authorize access. Test validation and affected browser flows.

Route files should export Route; keep their page component functions local so the Vite plugin can split each page into its own chunk.
