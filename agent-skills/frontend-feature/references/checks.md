# Acceptance checks

Check keyboard order, focus visibility, validation association and light/dark layout. Test cache isolation when switching identities/institutions. Confirm app source does not import database or auth/server. Use real API behavior for browser verification; record external blockers.

For visual changes, review the affected screen against [visual-design.md](visual-design.md). Verify the type scale, grid alignment, panel radii, dividers, copy and interactive states in the browser at desktop and narrow widths. Confirm no emojis, banned fonts or decorative effects were introduced. Check keyboard focus, reduced motion and light/dark contrast alongside hover states. Report only checks actually performed.
